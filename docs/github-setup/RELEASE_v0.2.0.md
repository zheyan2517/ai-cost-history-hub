## AI Cost History Hub v0.2.0

Source-only release focused on cross-platform reliability, local safety, and
maintainer-ready verification.

### Highlights

- Cross-platform Rust path handling for Windows, macOS, and Linux
- Isolated Windows test homes and removal of Unix-only test assumptions
- Clean-install verification and a coordinator smoke-test workflow
- Loopback-only dashboard and portal services by default
- Updated source-only documentation and release metadata

### Quick start

```bat
start.bat
```

Requires Python 3.12+.
