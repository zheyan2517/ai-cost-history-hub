## AI Cost History Hub v0.1.0

Initial public maintainer release.

### Highlights

- Local cost analytics service and unified portal launcher (`start.bat`)
- Loopback-only binding (`127.0.0.1`) by default
- Light theme for the cost UI
- Desktop history viewer entry for the local cost dashboard
- English-only product docs and UI language pin
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, issue/PR templates

### Quick start

```bat
start.bat
```

Requires Python 3.12+.
