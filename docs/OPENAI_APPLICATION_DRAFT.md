## Short description

AI Cost History Hub is a local, privacy-first product for AI coding-agent conversation history and API cost analytics. It provides a loopback-only cost dashboard and portal, plus an optional desktop history viewer that can open the cost UI in one click. The codebase is maintained as ongoing secondary development and refactoring of the local tooling stack.

## Why it matters

Developers using coding agents accumulate large amounts of local session data and spend without a unified offline view. This project helps users inspect history and cost breakdowns **without uploading sessions to a third-party cloud**.
