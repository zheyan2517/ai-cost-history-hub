## Short description (1–2 sentences)

AI Cost History Hub is a local, privacy-first workspace for AI coding-agent conversation history and API cost analytics. It runs a loopback-only cost dashboard and portal, with an optional desktop history viewer that can launch the cost sidecar in one click.

## Why it matters

Developers using Claude Code, Codex CLI, Gemini CLI, and related agents accumulate large amounts of local session data and spend without a unified offline view. This project helps maintainers and power users inspect history and cost breakdowns **without uploading sessions to a third-party cloud**.
